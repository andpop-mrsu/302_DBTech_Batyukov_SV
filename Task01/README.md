# Task01 - Каталог исходных данных

## Описание структуры файлов данных

### Исходные данные
* `genres.txt` - список жанров фильмов
* `movies.csv` - содержит информацию о фильмах, в том числе:
    * `movieId`- идентификатор фильма
    * `title` - название фильма
    * `genres` - название жанров( для фильмов с несколькими жанрами через `|`)
* `occupation.txt` - список профессий пользователей
* `ratings.csv` - содержит информацию о оценках, поставленных пользователями фильмам, в том числе:
    * `userId` - идентификатор пользователя
    * `movieId` - идентификатор фильма
    * `rating` -  оценка фильма
    * `timestamp` - временная метка
* `tags.csv` - содержит информацию о тегах, выставленных пользователями фильмам, в том числе:
    * `userId` - идентификатор пользователя
    * `movieId` - идентификатор фильма
    * `tag` - название тега
    * `timestamp` - временная метка
* `users.txt` - содержит информацию о пользователях, в том числе:
    * `userId` - идентификатор пользователя
    * `name` - имя пользователя
    * `email` - электронная почта пользователя 
    * `gender` - половая принадлежность пользователя
    * `birthdate` - дата рождения пользователя
    * `occupation` - профессия пользователя

### Служебные файлы
* `ratings_count.txt` - содержит 2 строки:
    * На первой строке записаны значение минимального идентификатора пользователя из файла `ratings.csv` и количество строк с этим идентификатором
    * На второй строке записаны значение максимального идентификатора пользователя из файла `ratings.csv` и количество строк с этим идентификатором
* `sqlite.txt` - содержит номер установленной версии SQLite и список доступных режимов вывода
