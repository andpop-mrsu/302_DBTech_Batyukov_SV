# Task02

## Требования к окружению 

Для корректной работы `db_init.bat` на компьютере должны быть установлены:

- **Python 3.6+** 
  - нужны только стандартные библиотеки: `csv`, `re`, `os`.
- **SQLite 3**
  - `sqlite3.exe` должен быть доступен в `PATH`
- **Git Bash** - для запуска `db_init.bat`,
  т.к. скрипт содержит bash-синтаксис (`#!/bin/bash`).
